# character-pipeline-v0.1 evidence

Generated by the commands in `run.txt` (native Windows, release build,
machine/toolchain recorded there). Profile revision **1**.

## What each artifact proves

- `board/board.png` — the 2048×1024 combined reference board: left half is the
  `biped-3q-v1` generation guide (pose authority), right half is
  `assets/mascot.png` (style authority) fit uniformly at scale 0.8166, centred,
  no crop. Proves the board composer produces deterministic composite output
  from (profile guide + arbitrary style image).
- `board/board.json` — receipt: profile id/revision + sha256; `guide` sha256/size
  (the sha256 equals the committed `assets/character-templates/biped-3q-v1/guide/dummy-generation.png`
  — the left panel is that exact render, pixel-identical); style image
  path/sha256/size; layout (board size, panel rects, fitted style_rect, scale);
  board PNG sha256; prompt `{path, sha256, bytes}` (absent without `--brief`);
  tool name+version. Any byte change in profile, guide, style image or output
  changes these hashes.
- `board/prompt.txt` — the profile's `prompt-template.txt` with `{brief}`
  replaced; sha256 recorded in `board.json`. Proves prompt assembly is
  deterministic and bound to the board via hash.
- `validation/<fixture>.json` — `mascot-character-validation/1` reports for the
  eight synthetic fixtures under `crates/mascot-character/fixtures/biped-3q-v1/`.
  Positive fixtures (`robot`, `mascot-like`) report PASS with 0 fail / 0 warn;
  the six `neg-*` fixtures each fail only for their stated reason(s) plus
  genuinely dependent findings. Deterministic finding order, no timestamps.
- `run.txt` — exact commands, stdout, exit codes and wall-clock timings.
